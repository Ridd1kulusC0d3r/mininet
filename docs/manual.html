1. Comece aqui — uma ação por vez

Não precisa instalar nada para ver funcionando. Se tiver Python 3, você roda os cases em segundos.

Veja rodando agora. Dois cliques em launchers/run-linux.sh (Linux/macOS) ou launchers/run-windows.bat (Windows). Ou no terminal: python3 cases/runner.py. Esperado: 12/12 PASS
Rode a suíte de testes. python3 -m pytest tests/ -q → 17 passed
Entenda. Leia a seção Como funciona e abra docs/lab-architecture.html.
Rode de verdade (opcional). Num Linux com root: sudo python3 cases/runner.py --mnsec. Veja Instalação.
💡 Modo sim × modo real. Tudo roda em "modo sim" (tráfego sintético) em qualquer computador, sem root. O "modo real" sobe a rede no Mininet e só funciona em Linux com privilégio de root.

2. Como funciona

A ideia central: cada detector é uma função pura que recebe uma lista de eventos de rede e devolve achados (findings). O mesmo detector é testado com eventos sintéticos (aqui, na nuvem) e usado com captura real no Mininet. O pcap vira evento, o evento vira achado, o achado vira evidência selada.

Por que isso importa: a lógica de detecção fica testável em qualquer lugar (CI/nuvem, sem root) e, ao mesmo tempo, reutilizável no laboratório real. O detector é a única fonte de verdade; só muda de onde vêm os eventos.

3. Instalação passo a passo

Escolha seu sistema. Para só ver os cases (modo sim), basta Python 3 — pule para a aba Qualquer SO.

Só precisa de Python 3.10+. Nada de root.

# 1. clonar
git clone https://github.com/Ridd1kulusC0d3r/mininet.git
cd mininet

# 2. (opcional) instalar pytest
python3 -m pip install pytest

# 3. rodar
python3 cases/runner.py        # 12 cases, modo sim
python3 -m pytest tests/ -q    # suíte de detecção
No Windows, dois cliques em launchers\run-windows.bat fazem os passos 2 e 3.

Para o modo real (Mininet puro). Requer root.

sudo apt update
sudo apt install -y mininet tcpdump python3-pip
# ferramentas de ataque dos cases (referência):
sudo apt install -y dsniff hping3 nmap hydra dnsmasq
python3 -m pip install scapy          # ler pcap

sudo python3 cases/runner.py --real

Para o modo Mininet-Sec nativo (NetworkTAP + captura embutida). Recomendado.

docker pull hackinsdn/mininet-sec
docker run --rm -it --privileged -v /lib/modules:/lib/modules \
  hackinsdn/mininet-sec /bin/bash

# dentro do container:
git clone https://github.com/Ridd1kulusC0d3r/mininet.git && cd mininet
python3 -m pip install scapy
python3 cases/runner.py --mnsec
Projeto Mininet-Sec: github.com/mininet-sec/mininet-sec (tag 1.2.0).

Windows não roda Mininet nativamente. Use WSL2 com Ubuntu e siga a aba Ubuntu/Debian.

# no PowerShell (admin):
wsl --install -d Ubuntu
# reinicie, abra "Ubuntu", e dentro dele siga a aba Ubuntu/Debian.
⚠️ O modo sim (python3 cases/runner.py e pytest) roda no Windows puro sem WSL. Só o modo real/mnsec exige Linux.

5. Arquitetura

O núcleo (lib/) é fixo; os backends de simulação são plugáveis. O sensor fica numa porta-espelho do switch e enxerga todo o segmento.

Diagrama isométrico da topologia (vítima, servidor, atacante, gateway, sensor na porta-espelho): abra docs/lab-architecture.html.

6. Geração de relatórios

Cada case grava uma evidência selada em out/. O hash cobre o corpo inteiro: qualquer alteração quebra a verificação — é cadeia de custódia leve.

{
  "case": "case01_arp_spoof",
  "max_severity": "critical",
  "finding_count": 1,
  "findings": [ { "detector": "arp_spoof", "technique": "T1557.002",
                  "severity": "critical", "evidence": { ... } } ],
  "sha256": "289004d20c2acd47f5890058b43e5c50ed5cda83f6d7762f583ae2256a40f383",
  "schema": "mininet-sec-lab/evidence/1"
}

Verificar a integridade

python3 -c "from lib.evidence import Evidence; \
print(Evidence.verify('out/case01_arp_spoof.json'))"
# True  → íntegra ; False → adulterada

8. Glossário

Mininet / Mininet-Sec
Emuladores que criam uma rede inteira (hosts, switches) dentro de um só Linux. Mininet-Sec adiciona nós e ferramentas de segurança.
Detector (função pura)
Função que, dada a mesma entrada, sempre produz a mesma saída, sem efeitos externos. Fácil de testar.
Evento normalizado
Um dicionário padronizado (arp, tcp, dns…) extraído da captura, que o detector consome.
Finding
Um achado de detecção: o quê, onde, severidade, confiança e a técnica MITRE.
Evidência selada
Relatório JSON cujo conteúdo é protegido por um hash SHA-256.
NetworkTAP / porta-espelho (SPAN)
Porta do switch que recebe cópia de todo o tráfego, para o sensor capturar.
MITRE ATT&CK
Catálogo mundial de técnicas de adversários. Cada case aponta sua técnica (ex.: T1557).
Half-open
Conexão TCP iniciada (SYN) que nunca completa o handshake — assinatura de SYN flood.
Modo sim × real
Sim = tráfego sintético, roda em qualquer lugar. Real = tráfego de verdade no Mininet (Linux+root).
